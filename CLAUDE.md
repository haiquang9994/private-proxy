# Project conventions

## Specs and plans

- Specs go in `docs/specs/YYYY-MM-DD-<topic>.md`; plans go in
  `docs/plans/YYYY-MM-DD-<topic>.md`. Never use `docs/superpowers/` or any other
  skill-default location, even when a skill says so.
- Specs and plans are written in English and start with a **Date** and a
  **Status** line (`Draft`, `Approved`, `Implemented`, `Superseded`).
- `docs/plans/` is git-ignored; specs are committed.
